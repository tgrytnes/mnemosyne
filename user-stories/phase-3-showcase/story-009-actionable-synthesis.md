### Wikilink Generation
```python
def generate_wikilinks(note_ids: List[str]) -> str:
    links = []
    for note_id in note_ids:
        note_path = get_note_path_from_graphos(note_id)
        note_title = extract_title(note_path)
        links.append(f"- [[{note_title}]]")
    return "\n".join(links)
```

### File Saving Logic
1. **Generate filename**: `2024-12-24-synthesis-docker-networking.md`
2. **Check existence**: If file exists, append `-v2`, `-v3`, etc.
3. **Write to Graphos mount**: `/vault/Synthesis/{{filename}}`
4. **Trigger Graphos sync**: Ensure immediate appearance in Obsidian
5. **Notify via Hermes**: Send Telegram message with link

### Auto-Tagging Strategy
- Extract tags from accessed clusters (Story 002 profiles)
- Add query-derived tags (NLP extraction of key terms)
- Always include: `#ai-generated`, `#synthesis`
