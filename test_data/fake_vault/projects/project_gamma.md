# Project Gamma

## Goal
Define a project plan for migrating the retrieval pipeline to a cleaner scope.

## Plan
- Draft milestones for the migration
- Confirm scope and dependencies
- Identify risks and mitigation

## Milestones
- Review current chunking and retrieval metrics
- Update vector storage assumptions
- Validate new scope with a small test vault

## Risks
- Underestimating effort
- Scope creep during discovery
